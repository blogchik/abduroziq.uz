# Font files

Static cuts generated by `scripts/build-fonts.py` (run from `apps/web`; needs
`pip install fonttools brotli`) from the font packages in `node_modules`. They exist because
the variable Newsreader files are about 130KB per style while the site uses five cuts of
about 22KB each, Caveat is only used for a few hand-written notes, and Geist Pixel only for
three small chips.

| File                                                              | Family in CSS      | Cut                                           | Source package                    |
| ----------------------------------------------------------------- | ------------------ | --------------------------------------------- | --------------------------------- |
| `newsreader-display-400(.italic).woff2`                           | Newsreader Display | optical size 72, weight 400                   | `@fontsource-variable/newsreader` |
| `newsreader-text-400(.italic).woff2`, `newsreader-text-600.woff2` | Newsreader Text    | optical size 20                               | `@fontsource-variable/newsreader` |
| `caveat-500.woff2`                                                | Caveat             | Basic Latin subset, no contextual alternates  | `@fontsource/caveat`              |
| `geist-pixel-square.woff2`                                        | Geist Pixel        | the Square cut, Basic Latin, no layout tables | `geist`                           |

Newsreader, Caveat and Geist (Vercel, with basement.studio) are licensed under the SIL Open
Font License 1.1 (see the `OFL-*.txt` files); the generated files are modified versions
under the same licence. Bricolage Grotesque and Geist Mono are loaded unmodified from their
Fontsource packages.
