## What it is

Payzone is a store for game currency. Players in Uzbekistan and the CIS top up PUBG Mobile, Mobile Legends, Valorant, Steam and other games here. An order is a player ID, a package and a payment, and part of every purchase comes back as Peasy Coin, the store's own cashback currency.

## My part

I build Payzone and keep it running: the storefront, the services behind it and the infrastructure they run on.

## How it is built

The storefront is a Next.js app in TypeScript, styled with Tailwind CSS. Behind it are Python services on FastAPI, with PostgreSQL, Redis and RabbitMQ. Everything is packaged with Docker and runs on Kubernetes.
