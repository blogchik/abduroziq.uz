## What it is

Three products for one trading academy. The public website presents the courses in Uzbek, Russian and English and takes applications. A lead API receives those applications. An in-house cabinet is where the team works: CRM, tasks, chats, lessons and quizzes.

## My part

Engineering across all three: the website, the API and the cabinet.

## How it is built

The website and the cabinet are Next.js apps in TypeScript. The API is NestJS with Prisma on PostgreSQL. The services run in Docker behind Caddy.

The pictures on this page show the public website only. The cabinet is internal.
