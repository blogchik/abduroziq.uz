## Bu nima

Bitta treyding akademiyasi uchun uchta mahsulot. Ochiq sayt kurslarni o'zbek, rus va ingliz tillarida taqdim etadi va arizalarni qabul qiladi. Lead API shu arizalarni qabul qilib oladi. Ichki kabinetda esa jamoa ishlaydi: CRM, vazifalar, chatlar, darslar va testlar.

## Mening ishim

Uchalasining muhandislik qismi: sayt, API va kabinet.

## Qanday qurilgan

Sayt va kabinet TypeScript'da yozilgan Next.js ilovalari. API NestJS'da, Prisma orqali PostgreSQL bilan ishlaydi. Servislar Docker'da, Caddy ortida ishlaydi.

Bu sahifadagi rasmlarda faqat ochiq sayt ko'rsatilgan. Kabinet ichki mahsulot.
